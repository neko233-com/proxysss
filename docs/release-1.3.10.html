v1.3.10 Linux 迁移稳定版本验证

2026-10-21 用户明确要求“没问题就全部发布”。本版本按 Linux nginx 迁移的功能与稳定性交付，仅 v1.3.10 豁免严格性能胜出及跨主机性能证据；生产 Linux 功能、产物和六平台打包仍需验收。不宣称 nginx 性能胜出、完整流式 gzip 等价、所有平台运行全绿或长期线上稳定。

当前验收与产物身份

功能源码候选 52b3259 的 Linux Bookworm x86_64 原生 Docker release 测试 419/419 通过，执行 59.53 秒。使用独立原生文件系统夹具，不把 Windows 共享目录当作 Linux 文件系统。该候选二进制 SHA256：98bbb4c074700869e79826c033283db11136756d947089e99c64089e207d673f；这是版本元数据更新前的功能候选，不能冒充最终 v1.3.10 附件。

该实际二进制在 2 CPU/768 MiB、无外网、只读根文件系统、无 capabilities 的独占容器中，既有 16 项独立 Go race 黑盒及新增 H1/H2 HEAD gzip/identity、ETag、Vary、独立响应头追加/替换、Range、SSE、未知长度 EOF 前传输检查全部通过。原始 H1 报文确认 HEAD 零正文；容器退出 0，无 OOM，专有资源已清理。

独占 4 GiB 容器中的 1 GiB 生成式上传精确收到 1,073,741,824 bytes，随后小请求 200；候选 VmHWM 2,118,740 KiB，容器 memory.peak 2,194,599,936 bytes。2 GiB payload 预算不是 RSS 上限，夹具不建立 1 GiB 副本/文件；不据此宣称任意并发容量。

最后 Vary-only 修正和隔离夹具的 v1.3.10 Linux 完整 release 测试 419/419 通过，执行 62.85 秒。Bookworm 构建二进制 SHA256 为 920de0e8e53d5e4fbe01d9b4a999c18e227f82a6e4c58863d77c81310be6e18f，面向现有 glibc 2.36 环境。官方平台附件由标签工作流另行打包，以 Release 实际附件为准；排队不代表发布成功，官方附件回下载与摘要核对属于独立验收。

Windows 实际限制

完整 cargo test --locked 初轮 381/391 通过、10 项失败。9 项 TLS 初始化失败来自直接构造配置后共享默认路径，已隔离相关 listener/UDP 夹具的证书与私钥并保留全部断言，listener 回归 2/2 通过。隔离后 IPv6 后端 echo 仍失败，专门 hostname/IPv6 用例串行也超时。

独立 .NET UDP loopback 不经过 proxysss/Tokio：IPv4 往返通过，IPv6 ::1 发送后接收超时。不改系统网络、不跳过或改写专门 IPv6 用例、不放宽证书匹配。隔离后 v1.3.10 完整重跑 384/391 通过、7 项 UDP 失败，执行 21.55 秒；非 IPv6 关键串行回归：方法/压缩 wire 5/5、HTTP 策略 10/10、HTTP/H2/SSE/WebSocket e2e 8/8 通过；不能声称 Windows 全绿，六平台打包不等于各平台运行验收。

能力边界

脚本 compression 省略/null 继承全局，显式对象整体覆盖。只有已知长度≤4 MiB、达到 min_length 且 MIME 允许的普通表示缓冲压缩；未知/大响应继续流式，SSE/206/已有编码不变换。未知/大表示保留协商策略的 Accept-Encoding Vary，但 HEAD 不假报未执行的压缩；已知小于最小长度不加该 Vary。压缩 HEAD 省略未知压后长度，实际变换及对应 HEAD 弱化强 ETag。

授权先于缓存/静态/上游，离线合成验证不等于任意外部服务验收。候选配置差分和线上切换单独验收，完成前保持待验收；不包含私有主机、域名、凭据或运维路径。未宣称长期浸泡、独立物理机性能、第三方 DNS/ACME 或全部安装器通过。
