混合负载与性能边界

11 类负载同时按 1×/2×/4× 运行。18 个窗口、198 个原始样本零错误，132 个等负载样本最低完成率 98%；活跃测量 18 秒，矩阵编排 172 秒。这不是长期浸泡或独立物理机证据。4× cgroup current/peak 为 proxysss 89264128/296955904、nginx 208248832/409784320 bytes，不作为活跃持有期每连接成本。

小文件吞吐为 nginx 的 1.863/1.997/1.730 倍，大文件为 0.714/0.640/0.679 倍。小文件 p99 与部分 HTTP/长连接延迟仍落后，本版本不宣称所有场景性能最优。

功能与审计记录保存在本地 .benchmark/blacklist-persistence-functional/，完整矩阵在 .benchmark/direct-ubuntu24-amd64/goal-blacklist-persistence/。本地已测 Linux release SHA256：5e11677be0544f0bf5b4f1f22ec3e0a24c0fc1a1136ac04db9c9ebed85f22711；平台发布包独立构建并提供自身摘要。
