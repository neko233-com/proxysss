# 火山引擎证书自动化所需权限

本文对应 proxysss 内建 ACME DNS-01 和 `volcengine_dcdn` 同步策略。先为自动化创建专用 IAM 身份，按实际项目和资源范围授权；不要使用主账号或把 Access Key 写进 YAML、仓库、日志或消息。以下是当前代码调用的 API；其他云产品的自动部署不在本策略覆盖范围内。

| 服务 | API 操作 | 作用 |
| --- | --- | --- |
| 公网云解析 DNS | `ListZones` | 查找要验证的 DNS 区域 |
| 公网云解析 DNS | `CreateRecord`、`DeleteRecord` | 创建本次 ACME TXT 验证记录并清理本次创建的记录 |
| 证书中心 | `ImportCertificate` | 导入新证书及私钥；相同证书复用已有实例 |
| 证书中心 | `CertificateGetInstanceList`、`CertificateDeleteInstance` | 启用旧证书清理时核对实例身份并删除符合条件的旧实例 |
| 全站加速 DCDN | `ListCertBind` | 查询已有域名与证书的关联及部署状态 |
| 全站加速 DCDN | `CreateCertBind` | 将新证书绑定到目标域名 |

DNS 的 IAM 动作前缀是 `dns:`；证书中心和 DCDN 的服务前缀分别为 `certificate_service:` 和 `dcdn:`。可以在 IAM 自定义策略编辑器中按上表选择对应动作，尽量限制到指定 DNS 区域、项目和 DCDN 域名；具体动作是否支持资源级限制以 IAM 控制台的权限摘要为准。需要列表类权限无法按单个资源限制时，再使用该动作所必需的范围。不要为了方便授予 `AdministratorAccess`、`IAMFullAccess` 或全部 DNS/DCDN 操作。

这些动作是按源码和官方 API 对照整理的最小功能清单；生产环境已验证所用身份可以完成签发和部署，但尚未用仅含上述动作的新 IAM 身份独立验证。因此不能把它描述为已验证可直接套用的最小权限策略。实际权限不足时检查服务端错误与火山操作审计，按拒绝的具体操作调整，避免扩大到所有产品。

## 部署与核验

1. 证书使用 proxysss 内建 ACME DNS-01 签发；泛域名证书通常同时包含根域名和泛域名 SAN。飞书通知与云同步可分别启停。
2. 为 `certificate_sync.targets` 配置证书文件、项目和至少一个已使用该证书的 DCDN 精确域名；密钥字段填写环境变量名称，由服务进程的受限环境文件注入。不要将真实值提交到开源仓库。
3. 同步先导入证书，再发现同一项目中与目标当前证书绑定的其他 DCDN 域名，验证新证书覆盖这些域名，然后逐项检查部署状态和 HTTPS 证书指纹。发现无法覆盖的域名或冲突时停止，不把部分失败当作成功。
4. `proxysss -c /path/to/proxysss.yaml certificate sync --target <目标名>` 手动触发；可重复 `--target` 或使用 `--all`。进程自动检查证书变化，也可以使用系统定时器定期调用。
5. 飞书成功卡片包含证书 ID、SAN 和 HTTPS 链接。出口 TLS 验证只说明发起同步的网络出口已看到证书，不代表每个全球边缘节点都已完成更新。

新签发通常产生新的证书中心实例。`cleanup_previous: true` 才开启自动清理：仅考虑本目标状态文件中记录的旧实例，在新证书全部 DCDN 部署并经当前出口核验后，核对旧实例为 proxysss 导入、检查无 DCDN 绑定，再请求证书中心删除；云端关联资源仍会阻止删除。首次启用不删除未记录实例。状态在证书目录持久化，失败保留并重试。其他云产品及外部服务器手工使用无法通过 DCDN 发现，开启前须确认；清理不能保证只剩一张证书。DNS-01 的 TXT 正常完成或报错后会清理；进程在创建记录后被强制终止时可能留下记录，应在 DNS 控制台核查。

## 凭据和网络

- 给专用身份使用受限 Access Key，按组织策略轮换。密钥一旦出现在聊天、日志或其他非安全渠道，应尽快更换并验证新密钥后停用旧密钥。
- 将环境文件限制为服务账号可读，并用 systemd `EnvironmentFile` 注入；更新环境后重启相关进程。不要通过命令行参数、URL 或公开文档传递密钥。
- 服务需要访问火山 DNS、证书中心、DCDN API、ACME CA、公共 DNS-over-HTTPS，以及已配置域名的 HTTPS；通知启用时还需访问飞书。必须保留 TLS 校验。
- `ProtectSystem=strict` 等文件系统沙箱需要允许 ACME 缓存和证书输出目录写入；继续限制其他目录。
