# v1.3.14 干净环境性能复验

2026-11-22 本地 Windows 主机 + Docker Desktop VM 上，同一 Ubuntu 24.04 `linux/amd64` 网关容器（`--cpus=1 --memory=2g`）对 v1.3.13 与 v1.3.14 做三轮同场景对照。客户端为 Windows 原生 Go HTTP/1.1 负载器，3 秒预热 + 10 秒测量，取三轮中位。

| 场景 | v1.3.13 中位 RPS | v1.3.14 中位 RPS | 变化 |
| --- | ---: | ---: | ---: |
| 1KB 静态 | 20,053 | 20,409 | +1.78% |
| 64KB 静态 | 15,171 | 15,052 | -0.78% |
| 1KB 反向代理 | 9,142 | 9,251 | +1.19% |

原始文件：

- `v1213-small-1..3.json`、`v1214-small-1..3.json`
- `v1213-large-1..3.json`、`v1214-large-1..3.json`
- `v1213-rp-1..3.json`、`v1214-rp-1..3.json`

这是发布后补充的单机 Docker 证据，不是严格跨主机/混合负载发布门禁，也不能用于宣称全面超过 nginx。详细说明见 `docs/RELEASE-1.3.14.md` 与 `docs/release-1.3.14.html`。
