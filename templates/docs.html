TCP / UDP

游戏 / 原生协议网关

UDP 容量包含在途创建与存活会话，满额保留活跃玩家并拒绝新建；失败和取消自动归还名额。会话容量、TTL 与热更新边界。

流式目标使用 host:port 或 [IPv6]:port，不加 tcp://、udp:// 或路径；主目标、候选池和权重键统一校验。UDP 域名仅在新会话建立时有界解析，已有数据报复用 socket。地址与 DNS 说明。

HTTP 面解决不了的实时流量，应该直接落到 tcp.listeners / udp.listeners。

文件协作入口

进阶配置

配置项速查

按协议与用途选择配置项，避免不同层的规则混用。

配置面 适合什么 常见误用
services.reverse_proxy.routes普通 HTTP / API / WebSocket / SSE 网站、后台、HTTP/2 gRPC、长响应 API、缓存、限流、健康检查都从这里开始。 不要拿它去承载 TCP / UDP 原生协议。
services.ai_proxyOpenAI-compatible / New API 代理到单个 New API/sub2api 服务，保持兼容 API 与流式响应。 普通网站代理请使用 reverse_proxy。
services.domain_routes域名与路径代理 按 domains 与 path_prefix 直接代理到 upstream，可设置路由证书策略。 不支持引用静态或 WebDAV 服务的嵌套 routes。
services.static_sites静态资源 / CDN 回源 HTML、CSS、JS、图片、字体、音视频、大文件下载、Range 断点续传。 不要把复杂业务鉴权写进静态文件层。
services.service_discoveryConsul / etcd / Nacos 把注册中心服务映射到 HTTP、TCP、UDP 上游池。 不要让每个数据面请求临时查注册中心。
tcp.listenersTCP 原生流量 数据库、游戏长连接、MQTT TCP、TLS passthrough/SNI 场景。 不要期待 HTTP 头级别策略。
udp.listenersUDP、KCP、QCP、CoAP-style 实时设备、游戏、会话型 UDP 网关。 不要把它包装成应用终端本身。

CDN 回源与安全目录服务

services.static_sites 支持回源令牌、TCP 对端 CIDR、短期 HMAC-SHA256 签名 URL、站点限流和缓存控制。鉴权先于文件缓存、HEAD、Range 与 304；签名资源返回 no-store。目录索引默认关闭，显式开启后支持大小、GMT 时间、安全链接和条目上限；默认隐藏点文件并检查真实路径边界。

源站令牌只鉴别 CDN，访客防盗刷和缓存命中时的授权须在 CDN 边缘执行。阅读完整配置、签名算法与幂等验证说明 →

安全开关与 Windows/macOS/Linux 适配

proxysss config security 输出安全开关、默认值和中文建议；CDN 鉴权与 FTP 策略可独立停用，保留规则。proxysss config performance 只读探测系统版本、I/O 后端和 socket 参数。Windows/macOS 保留 TCP 自动调节，并提供 keepalive、有界 UDP 缓冲；Linux 延续发行版与 CPU 自适应策略。Windows/macOS 保持现有调度，系统适配只作用于 socket；Linux 保留 CPU 自适应数据运行时。runtime.performance 在启动时固定，修改后需重启。

Docker 验证固定使用 proxysss-verify，运行前后清理同名项目容器，报告覆盖写入项目内固定目录。查看完整配置、安全建议和验证边界

游戏资源与复杂下载

原生静态服务支持单段和最多 16 段 Range，合并重叠区间并流式发送 multipart/byteranges。HEAD 忽略 Range；条件失败返回 412，全部越界返回 416。大文件局部读取不载入整文件，取消释放资源。脚本 API 无需变化。

静态虚拟主机

使用 services.static_sites[].hosts 与 path_prefix 按域名分发资源，多站点预热与连接缓存保持隔离。匹配语法、优先级、重载和鉴权边界统一见 CDN 域名隔离指南。

TCP/UDP 新会话共用 stream 限流、动态黑名单、DDoS 和 allow/deny；UDP 已有数据报不重复扣连接配额。准入与重载边界。

独立控制任务每秒回收过期 DDoS、admin/monitor 登录失败窗口和动态黑名单，保留活动窗口及封禁，无需开启热重载或健康探测。黑名单查询不会删除并发续封的新值；封禁时长按单调时间计算，超大秒数不导致未来时间点溢出，并发登录失败不重置有效锁定。

动态黑名单持久化保存原始 UTC 起点与 TTL，重启不续成一小时，损坏的启用快照拒绝启动。管理操作完成原子文件替换后才更新内存/DDoS，失败返回 500；成功响应 persisted 表明是否保存，单 writer 的锁不进入普通准入路径。未持久化的内存封禁同样约束后续 HTTP/AI 请求与新 WS 握手，已有 WS/TCP relay 保留。文件格式、重启与失败语义。

脚本保护的静态文件

script_only: true 站点只由 proxysss://static-site/<name> 显式选择，原生匹配与快缓存不能绕过脚本；保留 Host/path、真实 peer、文件授权和 HEAD/Range。可选 spa_fallback 仅适用于合法缺失目标，目录缺 index、隐藏路径及越界链接不回退。

路由授权与 TLS 重载

原生 auth_request 在缓存和业务上游前异步授权；脚本支持合成状态/响应头和独立路由超时，可显式覆盖普通回源方法并追加独立重复响应头。HEAD 转 GET 保留元数据且前端无正文，HEAD 缓存仍 bypass。路由压缩省略时继承全局，仅已知长度≤4 MiB 的合格表示收集压缩；未知/大响应继续流式，SSE/206/已有编码不变换，保留 Vary 并隔离源站编码缓存；不宣称完整 nginx 流式 gzip 等价。strict SNI 使用显式域名白名单；证书/私钥整对验证后发布，失败保留旧监听。配置、默认值与失败边界
